# Agent Skills

## Overview
This document outlines the skills and capabilities available to the development agent.

## Core Skills

### 1. Code Analysis & Refactoring
- Analyze existing code for performance issues
- Identify code smells and anti-patterns
- Suggest and implement code improvements
- Apply modern best practices and patterns

### 2. React Development
- Component architecture and design patterns
- State management (useState, useEffect, useContext, useReducer)
- React Router implementation
- Performance optimization (memo, useMemo, useCallback)
- Custom hooks development

### 3. JavaScript/TypeScript
- Modern ES6+ features
- Type safety with TypeScript
- Asynchronous programming (Promises, async/await)
- Module systems and bundlers

### 4. CSS & Styling
- CSS modules and preprocessors
- Responsive design principles
- CSS-in-JS solutions
- Tailwind CSS and utility-first frameworks

### 5. Build Tools & Development
- Vite configuration and optimization
- ESLint and Prettier setup
- Testing strategies (Jest, React Testing Library)
- Git workflow and version control

## Specialized Skills

### 6. Web Performance
- Bundle optimization
- Lazy loading and code splitting
- Image optimization
- Caching strategies

### 7. Accessibility (a11y)
- WCAG compliance
- Semantic HTML
- Keyboard navigation
- Screen reader support

### 8. Security Best Practices
- XSS prevention
- Input validation
- Secure coding patterns

## Frontend Design Skills

### 9. Premium UI Design
- **Color Systems**: Gold-accented luxury palettes, dark mode themes, gradient systems
- **Typography**: Serif/sans-serif pairings, responsive typography with clamp(), elegant font stacks
- **Spacing**: Consistent vertical rhythm, section padding, responsive breakpoints
- **Glassmorphism**: Frosted glass effects, backdrop filters, translucent UI elements
- **Neumorphism**: Soft UI, subtle shadows, pressed effects

### 10. Modern CSS Techniques
- **Custom Properties**: CSS variables for design tokens, theme switching
- **Animations**: Keyframe animations, shimmer effects, smooth transitions, reduced motion support
- **Gradients**: Linear gradients, gold accents, premium color transitions
- **Shadows**: Layered shadows, colored glows, depth effects
- **Responsive Design**: Mobile-first approach, fluid typography, flexible layouts

### 11. Component Design Patterns
- **Cards**: Premium card designs with hover effects, subtle elevation
- **Buttons**: Gradient buttons, glass buttons, micro-interactions
- **Navigation**: Sticky navbars, smooth scroll, active states
- **Hero Sections**: Full-screen backgrounds, overlay gradients, animated content
- **Loading States**: Shimmer placeholders, skeleton screens

### 12. Visual Enhancements
- **Selection Styles**: Custom text selection colors
- **Scrollbars**: Custom scrollbar design matching theme
- **Focus States**: Accessible focus rings, keyboard navigation
- **Noise Textures**: Subtle grain overlays for depth
- **Vignettes**: Dark overlays for text readability

## How to Use
When requesting assistance, specify which skill area you need help with, and the agent will apply the appropriate techniques and patterns.
